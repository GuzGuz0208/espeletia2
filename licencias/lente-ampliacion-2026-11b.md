# Lente: ampliación del 26-nov-2026 (loricaria y pajonal)

se guarda su huella (1.280 números calculados en el navegador con el mismo modelo MobileNetV2 que usa el teléfono); la
foto no se copia en la app. Se revisaron a mano: se quitaron polillas del género homónimo *Loricaria*, fotos con manos,
cielo o una sola espiga. Se probaron también valeriana y romero de páramo y se descartaron (la valeriana de Colombia es
sobre todo de bosque y el romero se confundía con el siete cueros).
